# CodeAlpha - Exploratory Data Analysis (EDA)

## Project Overview
This repository contains the Exploratory Data Analysis (EDA) for the **Online Store Orders** dataset as part of the **CodeAlpha Data Analytics Internship**[cite: 1]. The primary objective of this project is to analyze customer buying behavior, identify top-performing revenue drivers, test business hypotheses, and uncover operational data anomalies[cite: 1].

## Key Highlights & Findings
* **Dataset Size:** 1,200 orders ($1.26M+ total sales revenue across 2023–2025).
* **Top Revenue Categories:** Office furniture and electronics lead overall sales (**Chairs** at $195.6k and **Printers** at $195.6k).
* **Operational Anomaly:** **41.4%** of all orders were either **Cancelled** (20.8%) or **Returned** (20.6%).
* **Hypothesis Testing:** Disproved the assumption that coupon codes increase Average Order Value (AOV); validated that unit price ($r = 0.72$) and quantity ($r = 0.62$) are the primary drivers of transaction value[cite: 1].

## Tech Stack & Tools
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / VS Code
